# Амёбы и хищники

Симуляция жизни амёб и хищников в лабиринте. Агенты исследуют поле, ищут пищу и добычу, размножаются и передают потомству генетические признаки. Поведение обучается методом Q-learning; успешные сессии сохраняются между запусками.

## Требования

- Python 3.12 (проверенная версия)
- Tkinter — обычно входит в установщик Python для Windows
- Зависимость из `requirements.txt`: `pygame==2.6.1`

## Запуск в Windows

Откройте PowerShell в папке проекта и выполните:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python main.py
```

При запуске автоматически выполняются тесты. Если они пройдены, откроется окно параметров. После завершения симуляции можно выбрать продолжение с теми же настройками или выход.

## Управление симуляцией

В окне параметров доступны настройки радиусов восприятия света и тепла, скорости амёбы, восстановления сытости на свету, потери сытости в темноте, расхода еды и порога яиц для зачёта обучения.

- **Предобучить и запустить** — сначала обучает оба вида заданное число циклов, затем запускает симуляцию. Успешные сессии обновляют таблицы обучения.
- **Запустить без предобучения** — запускает поле сразу, используя сохранённые таблицы, если они есть.
- Закройте окно симуляции, чтобы завершить текущую сессию. В окне параметров появится предложение продолжить или выйти.

Симуляция идёт на поле размером 800 × 600. Амёбы ищут пищу и ориентируются на следы сородичей; хищники ищут амёб, а процесс поедания занимает 3 секунды симуляционного времени. При численности вида выше пяти расход сытости возрастает: шестая особь добавляет 10%, каждая следующая — ещё 5%. При снижении численности коэффициент автоматически уменьшается.

## Данные и логи

- `q_table.json` — обучение амёб.
- `predator_q_table.json` — обучение хищников.
- `simulation_logs/` — логи запусков в формате JSONL; создаются автоматически.
- `analyze_logs.py` — сводка по длительности, численности, рождениям, смертям, обучению и предупреждениям.

Проанализировать все логи:

```powershell
python analyze_logs.py
```

Проанализировать один запуск или сохранить данные:

```powershell
python analyze_logs.py simulation_logs\run-YYYYMMDD-HHMMSS-ffffff.jsonl
python analyze_logs.py --json
python analyze_logs.py --csv population.csv
```
